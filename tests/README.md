# Tests à développer avant pilote
- Authentification : compte désactivé, mauvais mot de passe, fixation de session.
- Autorisations : agent ne peut pas créer de compte ni valider un import.
- Recherche publique : réponse uniforme, limite de tentatives, aucune donnée sensible.
- Import : extension falsifiée, fichier trop volumineux, en-têtes manquants, doublons.
- Retrait : statut non disponible, identité non vérifiée, double remise concurrente, rollback.
- Audit : action sensible enregistrée.
